# Starter README for the per-student homework repositories

`scripts/create_hw_repos.sh` writes everything below the `---` into each student's
repository as its `README.md`, and re-running the script refreshes it everywhere.

Keep this short. It lives in a different repository from the course documentation,
so anything restated here can drift out of step with
[assignments/README.md](README.md) — which is the single source of truth for what
is collected, the deadline table, and the late policy. This file should carry only
what a student needs *at the moment of uploading*, and link out for the rest.

---

# ECON 630 — your homework repository

This repository is **yours and private** — your classmates cannot see it.

Besides you and me, the administrators of the `uh-manoa-uhero` organization can
read it. Organization administrators have access to every repository the
organization owns.

## Uploading a submission

1. **Add file → Upload files**
2. Drag in your PDF, named `weekNN.pdf` — `week02.pdf`, `week03.pdf`, and so on.
   No name or date in the filename; the repository already identifies you.
3. **Commit changes**

That is a complete submission. You never need Git, a terminal, or any software.

Uploading the wrong file is harmless — upload a corrected one before the deadline
and I grade the most recent version in place at that time.

## Everything else

Deadlines, what each week's write-up must contain, and the late policy are in the
course repository:

- **[The weekly write-up: what, when, and how](https://github.com/uh-manoa-uhero/econ630/blob/main/assignments/README.md)**
  — including the deadline table
- **[Syllabus schedule](https://uh-manoa-uhero.github.io/econ630/)** — which chapter
  and videos each week covers

In short: due **8 pm on the Sunday before** that week's sessions, hand-written,
one PDF. GitHub timestamps every upload.

## If something goes wrong

If something is wrong with *this repository* — a failed upload, an access error —
email <fuleky@hawaii.edu> early. For questions about the *material*, use
[Q&A](https://github.com/uh-manoa-uhero/econ630/discussions) so the whole class
benefits from the answer.
