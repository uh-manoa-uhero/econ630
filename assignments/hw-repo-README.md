# Starter README for the per-student homework repositories

`scripts/create_hw_repos.sh` writes everything below the `---` into each student's
repository as its `README.md`. Kept here so the wording is versioned and reusable:
edit once, and re-running the script refreshes it everywhere.

---

# ECON 630 — your homework repository

This repository is **yours and private**. Only you and the instructor can see it.
Your classmates cannot.

## What to upload

One PDF per week, containing your **hand-written** summary of the week's material
and your solutions to that week's **conceptual** exercises. Scan or photograph the
pages and combine them into a single PDF.

Name it `weekNN.pdf` — `week02.pdf`, `week03.pdf`, and so on. Nothing else, no
name or date in the filename; the repository already identifies you.

Which exercises belong to which week is listed in
[the assignments directory](https://github.com/uh-manoa-uhero/econ630/tree/main/assignments)
of the course repository, along with the full table of deadlines.

## How to upload

You do not need Git, a terminal, or any software:

**Add file → Upload files** → drag your PDF in → **Commit changes**.

That is a complete submission. Uploading through the website is all that is asked
of you, and you never need to learn anything about how Git works.

## Deadlines

**8:00 pm on the Sunday before that week's sessions.** The full table is in the
course repository.

GitHub records the moment of every upload, and that record is what I grade against
— a file committed after 8 pm is late and earns no credit. The repository stays
open, so nothing stops you uploading late; it simply will not count. Submit an
incomplete write-up rather than nothing: partial credit is real, a missing
submission is a zero.

If you upload the wrong file, upload a corrected one before the deadline. I grade
the most recent version that was in place at the deadline.

## Feedback

I comment by opening an issue in this repository, or by replying in the commit for
that week. You will get an email either way. Grades are recorded separately and
returned to you directly.

## If something goes wrong

Email <fuleky@hawaii.edu>. If the problem is with this repository — a failed
upload, an access error — say so early. Discovering it at 7:50 pm on Sunday is not
a reason the deadline moves.

For questions about the *material*, use
[Q&A in the course repository](https://github.com/uh-manoa-uhero/econ630/discussions)
so the whole class benefits from the answer.
