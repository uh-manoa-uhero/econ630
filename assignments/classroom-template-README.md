# Starter README for the Classroom template repository

This is the text to put in `README.md` of the **template repository** that GitHub
Classroom uses as starter code (suggested name:
`uh-manoa-uhero/econ630-homework-template`, marked as a template in its settings).

Every student repository Classroom creates starts from that template, so this is
the first thing a student sees when they accept an assignment. Kept here so it is
versioned and reusable — edit once, and every future week inherits the change.

Replace `NN` nowhere: leave it generic, since one template serves all fifteen
weeks.

# Weekly homework — ECON 630

This repository is **yours and private**. Only you and the instructor can see it.
Your classmates cannot.

## What to do

1. Do the week's work as described in the assignment spec — see
   [the assignments directory](https://github.com/uh-manoa-uhero/econ630/tree/main/assignments)
   in the course repository for the reading, videos, and which conceptual
   exercises to write up.
2. Write your summary and exercise solutions **by hand**, on paper.
3. Scan or photograph the pages and combine them into **one PDF**.
4. Upload it here, named `lastname-weekNN.pdf` — for example
   `kealoha-week03.pdf`.

## How to upload

You do not need Git, a terminal, or any software. In this repository:

**Add file → Upload files** → drag your PDF in → **Commit changes**.

That is a complete submission. If you spot a mistake, upload a corrected file
before the deadline; whatever is here at the cutoff is what gets graded.

## Deadline

**Sunday 8:00 pm.** At that moment this repository becomes read-only and no
further uploads are possible. This is automatic — there is no late window and
nothing to appeal to.

Submit an incomplete write-up rather than nothing. Partial credit is real; a
missing submission is a zero.

## If something goes wrong

Email <fuleky@hawaii.edu>. If the problem is with this repository — a broken
link, a failed upload, an access error — say so early. Discovering it at 7:50 pm
on Sunday is not a reason the deadline moves.

For questions about the *material*, use
[Q&A in the course repository](https://github.com/uh-manoa-uhero/econ630/discussions)
instead, so the whole class benefits from the answer.
